# Политика конфиденциальности расширения Unique Requisites

*Расширение для Google Chrome «Unique Requisites». Последнее обновление: сентябрь 2026.*

## Общие положения

Расширение Unique Requisites не собирает, не продаёт и не передаёт третьим лицам никакие данные. Вся обработка происходит локально в браузере пользователя.

## Какие данные используются

Когда пользователь нажимает «Показать реквизиты» на странице игрока в админ-панели **lixog.com**, расширение запрашивает у этой же админ-панели список номеров платёжного счёта игрока. Запрос выполняется с использованием текущей сессии пользователя в браузере. Полученные данные только отображаются в окне расширения, чтобы их можно было скопировать, и никуда больше не отправляются.

## Какие данные хранятся

Последний полученный список (ID игрока и номера платёжного счёта) сохраняется на устройстве пользователя во встроенном хранилище Chrome, чтобы он не пропадал после закрытия окна расширения. Удалить эти данные можно в любой момент кнопкой «Очистить» или удалив расширение.

## Сторонние сервисы

Не используются. Расширение обращается только к **lixog.com**.

## Отслеживание

В расширении нет аналитики, отслеживания, отчётов об ошибках и любой другой телеметрии.

# Privacy Policy — Unique Requisites Chrome Extension

*Last updated: September 2026.*

## Overview

Unique Requisites does not collect, sell, or share any data. All processing happens locally in the user's browser.

## Data accessed

When the user clicks "Show requisites" on a player page of the **lixog.com** admin panel, the extension requests the player's payment account numbers from the same admin panel using the user's existing browser session. The data is only displayed in the extension so it can be copied, and is never sent anywhere else.

## Data stored locally

The last retrieved list (player ID and payment account numbers) is saved on the user's device using Chrome's built-in storage so it remains visible after the extension window is closed. It can be deleted at any time with the "Clear" button or by removing the extension.

## Third-party services

None. The extension communicates only with **lixog.com**.

## No tracking

The extension contains no analytics, tracking, crash reporting, or telemetry of any kind.
