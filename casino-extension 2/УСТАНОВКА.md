# Установка Player Analytics

1. Открой Chrome и перейди по адресу: `chrome://extensions`

2. Включи **Режим разработчика** (переключатель в правом верхнем углу)

3. Нажми **«Загрузить распакованное»**

4. Выбери папку `casino-extension`

5. Расширение появится в списке — закрепи его на панели через иконку пазла 🧩

---

**Обновление после изменений в коде:**  
Зайди в `chrome://extensions` → найди Player Analytics → нажми кнопку обновления (⟳)

**Важно:** для работы расширения нужно быть залогиненным в `lixog.com/ru/admin` и `sb2admin-altenar2.biahosted.com`
